# wasmtest run exclusions — the written taxonomy for the wasm cuts.
#
# A `.wast` listed here prints as `skip` when a suite is run, so a file the
# engine cannot yet handle does not fail the CI gate. Each entry names the
# file and why it is excluded; a file belongs here only while a later cut owns
# its feature. The in-process converter (the `wast` crate) parses every entry;
# the remaining reasons are engine-side or Cut 9 work.

# Harness tooling the engine has no counterpart for.
waspec/test/core/annotations.wast :: annotation directives are harness tooling, not engine features
waspec/test/core/instance.wast :: module-linking `(instance ...)` is outside the supported corpus
waspec/test/core/names.wast :: export names use confusing-unicode strings the `wast` lexer rejects

# GC-era type sections and heap types still behind the Cut 9 residual
# (isorecursive rec-group canonicalization: cross-module type equality must
# respect rec-group shape, not just structure).
waspec/test/core/type-equivalence.wast :: GC `rec` type bags and subtyping (Cut 9)
waspec/test/core/type-rec.wast :: recursive GC type groups (Cut 9)
waspec/test/core/exceptions/tag.wast :: the `rec`-typed tag fixtures use GC type groups (Cut 9)

# The GC proposal corpus: one remaining file uses multi-supertype fixtures the
# `wast` grammar (and the decoder's single-supertype model) rejects; the rest
# of the directory runs green as of Cut 9 wave 3.
waspec/test/core/gc/type-subtyping.wast :: multi-supertype fixtures the `wast` grammar rejects (Cut 9)

# JS-API fixtures (`wasmtest jsapi`). `limits.any.js` is the embedder-limit
# conformance file (WPT marks it `timeout=long`): it builds and validates
# million-element modules, which takes minutes or more in the debug engine
# (which enforces no embedder limits); it is run on demand, not in a sweep.
waspec/test/js-api/limits.any.js :: embedder-limit conformance builds 1M-element modules (WPT timeout=long); run on demand

# The JS-string and GC proposals are outside the supported JS-API corpus (see
# the wave 5 slices in .notes/wasm-plan.md): no later cut owns them.
waspec/test/js-api/js-string/basic.any.js :: JSString proposal (out of scope)
waspec/test/js-api/js-string/constants.any.js :: JSString proposal (out of scope)
waspec/test/js-api/js-string/imports.any.js :: JSString proposal (out of scope)
waspec/test/js-api/js-string/polyfill.js :: JSString proposal (out of scope)
waspec/test/js-api/gc/casts.tentative.any.js :: GC proposal (out of scope)
waspec/test/js-api/gc/default-value.tentative.any.js :: GC proposal (out of scope)
